## class-note-kit

### 왜 만들었나

수업을 들을 때마다 같은 일을 했다. 노드 원문을 복사해 AI에게 주고, 정리본 PDF를 만들고, 노션에 붙여넣을 요약을 만들고, 발표대본을 뽑는다. 회차마다 반복이었다.

문제는 **매번 같은 설명을 다시 했다**는 것이다.

> "지난 회차 것 참고해서 같은 스타일로."
> "표지에 뭘 뺐고 뭘 다시 그렸는지 적어 줘."
> "회고는 어제 회고랑 이어서 써 줘."
> "노션에 붙여넣을 수 있게 `#` 빼고 블록으로 잘라 줘."

한 회차에 네댓 번씩, 여덟 번째 회차까지 반복했다. 그러다 보니 **말할 때마다 결과가 조금씩 달라졌다.** 어느 날은 표지에 편집 방침이 빠지고, 어느 날은 파일명 형식이 어긋났다.

결정적이었던 건 발표대본이었다. "3분 05초"라고 적어 뒀는데 실제로 세어 보니 **3분 27초**였다. 눈대중으로 적은 숫자였다. 발표장에서 알았으면 늦었을 것이다.

그래서 옮겼다. 반복하던 설명은 `SKILL.md`로, 눈대중하던 계산은 스크립트로.

### 무엇이 달라졌나

**전** — 회차마다 4~5번의 반복 설명 + 결과가 매번 조금씩 다름 + 시간은 눈대중

**후** — `"오늘 수업 자료 정리해 줘"` 한마디 + 규칙이 파일에 고정 + 시간은 실측값

### 무엇을 만들어 주나

`YYYY년MM월DD일/` 폴더에 다섯 개.

| 파일 | 내용 |
|---|---|
| `AI에이전트2기교육_….html` / `.pdf` | A4 조판 정리본. 표지·목차·섹션·콜아웃, 도해는 SVG |
| `학습템플릿_….md` / `.pdf` | 주제2 · 목표2 · 학습내용 콜아웃 · 질문2 · 회고2 |
| `노션붙여넣기_….md` | 노션에 그대로 붙여넣게 `=====` 블록으로 절단 |
| `발표대본_….md` | 3분 발표. **낭독 시간 실측**, 예상 질문 대비 |

### 설치

```bash
git clone https://github.com/ldk1575/my-skills.git
```

```bash
cp -r my-skills/.claude/skills/class-note-kit ~/.claude/skills/
```

Claude Code를 **재시작**하면 인식된다. (프로젝트에서만 쓰려면 `~/.claude/skills/` 대신 그 프로젝트의 `.claude/skills/`에 두면 된다.)

### 쓰는 법

새 대화를 열고 수업 노드 원문을 붙여넣은 뒤, 한마디만 하면 된다.

```
2026년 9월 7일 수업 내용이야. 오늘 수업 자료 정리해 줘.
```

스킬이 알아서 날짜 폴더를 만들고 다섯 개를 생성한 뒤, PDF가 실제로 열리는지까지 확인해 보고한다.

### 스크립트만 따로 써도 된다

```bash
bash .claude/skills/class-note-kit/scripts/html2pdf.sh 문서.html
```
> `완료: 문서.pdf  (480155 bytes, 7쪽)`

```bash
python .claude/skills/class-note-kit/scripts/reading_time.py 대본.md
```
> ```
> 전체    : 1,104자  →  3분 21초
> 뺄 곳   : 130자   →  0분 24초
> 축약 시 : 974자   →  2분 57초
> ```
> 머리말에 붙여넣을 문장까지 만들어 준다.

### 구조

```
class-note-kit/
├── SKILL.md              순서 · 판단 기준 · 통과 기준 (얇게)
├── references/           산출물별 상세 규칙 4개 — 필요할 때만 읽힌다
│   ├── lecture-doc.md      정리본 조판 (섹션·콜아웃·SVG·표·출처)
│   ├── study-template.md   학습템플릿 6블록
│   ├── notion-paste.md     노션 절단 규칙
│   └── talk-script.md      3분 대본 + 시간 실측
├── assets/print.css      A4 조판 CSS
└── scripts/
    ├── html2pdf.sh         HTML → PDF (헤드리스 Chrome)
    └── reading_time.py     낭독 시간 실측
```

`SKILL.md`를 일부러 얇게 뒀다. Claude는 평소 스킬의 이름과 설명 한 줄만 읽고 있다가 필요할 때만 본문을 펼치는데(**점진 공개**), 본문에 규칙을 다 넣으면 그 이점이 사라진다. 그래서 상세 규칙은 `references/`로 빼고 본문에서는 가리키기만 한다.

### 다른 수업에도 쓰려면

`SKILL.md`에서 파일명 규칙(`AI에이전트2기교육_…`)만 바꾸면 된다. 나머지 — 조판, 시간 실측, 노션 절단 — 는 과정과 무관하다.

### 만든 환경

Windows 11 · Claude Code · Python 3 · Chrome(또는 Edge).
`html2pdf.sh`는 macOS·Linux의 Chrome/Chromium 경로도 찾는다.
