# 노션 붙여넣기용 규칙

`노션붙여넣기_YYYYMMDD_<주제>.md` — 학습템플릿과 **같은 내용**을, 노션에 그대로 붙여넣을 수 있게 잘라 둔 것.

## 왜 따로 만드나

마크다운을 노션에 통째로 붙이면 세 가지가 깨진다.

1. **첫 줄의 `#`은 변환되지 않는다** — 노션이 첫 블록은 그대로 텍스트로 받는다
2. **노션 템플릿에 이미 섹션 제목이 있다** — `## 오늘의 주제`를 또 붙이면 제목이 두 번 나온다
3. **콜아웃은 마크다운에 문법이 없다** — 먼저 빈 콜아웃을 만들고 그 안에 붙여넣어야 한다

그래서 이 파일은 **`#` 제목 없이**, 붙여넣을 덩어리만 잘라 두고 안내문을 붙인다.

## 파일 형식

```
노션 붙여넣기용 · YYYY-MM-DD <주제> · <작성자>

▶ 안내문 (복사하지 않는 줄)
▶ 콜아웃 N개가 필요합니다. 하나 만들고 Ctrl+D 로 N-1번 복제하면 빠릅니다.
▶ ===== 로 감싼 구역만 복사하세요.


▶▶ ① 템플릿 「오늘의 주제」 아래 빈 블록에 붙여넣기
=====
1. **…**
    - …
=====


▶▶ ② 템플릿 「오늘의 목표」 아래 빈 블록에 붙여넣기
=====
…
=====
```

## 두 가지 기호

| 기호 | 뜻 |
|---|---|
| `▶` / `▶▶` | **안내문.** 복사하지 않는다. 어디에 붙일지 알려 주는 줄 |
| `=====` | **복사 경계.** 이 사이만 긁어서 붙여넣는다 |

## 블록 순서

1. 오늘의 주제
2. 오늘의 목표
3. 오늘의 학습 내용 — 먼저 `/토글`로 토글을 만들고 이름을 넣게 안내, 그 안에 콜아웃 N개
4. 콜아웃 1 … N (마지막은 '오늘의 한 줄')
5. 오늘의 질문사항 — Q1, Q2 각각 별도 블록
6. 오늘의 회고
7. 마무리 안내 — *"다 채운 뒤 이 페이지를 노션 템플릿으로 저장해 두세요"*

## 콜아웃 블록 쓰는 법

노션에서 콜아웃 안에 붙여넣으면 **첫 줄이 콜아웃 제목**이 되고 나머지 불릿이 자식으로 들어간다.
그래서 `=====` 안의 첫 줄은 **`- ` 없이** 제목만 쓴다.

```
=====
1. 에이전트란 무엇인가 — 모델 + 하네스, 그리고 루프
- **에이전트 = …**
- **어시스턴트와의 차이는 …**
=====
```

## 학습템플릿과 다른 점 — 이것만 조심

| | 학습템플릿 md | 노션 붙여넣기용 md |
|---|---|---|
| `#` 제목 | 있음 | **없음** |
| 콜아웃 표시 | `**[콜아웃]**` 로 표시만 | `=====` 로 실제 절단 |
| 안내문 | 상단에 3줄 | `▶` 로 블록마다 |
| ⚠️ 이모지 | 써도 됨 | **쓰지 않는다** — 노션 콜아웃 아이콘과 겹쳐 지저분해진다 |

내용 자체는 **글자 하나까지 같게** 유지한다. 한쪽만 고치면 다음 회차에 어긋난다.
