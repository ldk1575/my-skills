# 수업 노드 → 원문 보관본 + 학습자료 5종

강의 원문을 받아, 날짜 폴더에 **원문 보관본 하나와 학습자료 다섯 개**를 만든다.

**원문은 두 갈래로 들어온다.**

| 들어오는 형태 | 할 일 |
|---|---|
| 사람이 본문을 붙여넣음 | 그대로 쓴다 |
| **`learn.modulabs.co.kr` 노드 링크** | 브라우저로 직접 읽어 온다 → **`references/modulabs-node.md`** |

---

## 시작 전에 확인할 것

아래 다섯 가지를 먼저 정한다. 사용자가 안 알려줬으면 **묻지 말고 정하되, 정한 값을 알린다.**

| 항목 | 정하는 법 |
|---|---|
| 날짜 | **수업일이 아니라 자료를 만드는 날**이 기본. 사용자가 다른 날짜를 지정하면 그것을 따른다 |
| 주제 | 공백 없는 한글 축약어 (`데이터베이스`, `트랜스포머로가는길`) |
| 출력 폴더 | `<작업폴더>/YYYY년MM월DD일/` |
| 직전 회차 | 같은 부모 폴더의 가장 최근 날짜 폴더. **있으면 그 스타일을 승계한다** |
| 원문 범위 | **노드 전체인지 일부 강인지.** 링크는 대개 한 강만 가리킨다 — 커리큘럼에서 전체 강 수를 확인한다 |

> **범위를 먼저 맞춘다.** 사용자가 "2·3·4강"이라고 해도 노드 전체가 8강이면
> 원문 보관본은 8강 전부를, 학습자료는 요청 범위를 다루는 식으로 갈릴 수 있다. **어느 쪽인지 한 줄로 확인한다.**

---

## 순서

### 0. 원문을 확보한다

링크로 들어왔으면 **`references/modulabs-node.md`** 를 그대로 따른다. 요약하면 —
**로그인은 사용자가 직접 / 강은 커리큘럼 목록을 클릭해 하나씩 / 클릭 뒤 5~6초 기다린 다음 읽기 /
「깊이 보기」·「손으로 돌려보기」 접힌 토글을 전부 펼쳐서 다시 읽기.**

**접힌 토글을 빼먹으면 자료의 절반이 날아간다.** 여기가 가장 잘 빠지는 자리다.

### 1. 직전 회차를 읽는다

있으면 정리본 HTML의 CSS와 학습템플릿 구성을 그대로 이어받는다. 없으면 `assets/print.css`로 시작한다.
**직전 학습템플릿의 회고도 이때 읽어 둔다** — 오늘 회고를 이어 쓰려면 필요하다.

### 2. 원문 보관본 — `노드원문_YYYYMMDD_<주제>.html` → `.pdf`

**본문 문장을 한 글자도 고치지 않고** A4로 조판한다. 학습자료보다 **먼저** 만든다.
바꾸는 것은 넷뿐이고, **표지에 그 넷을 명시한다.**

1. **사진**은 라이선스를 확인해 **되면 그대로 싣고** 저작자·라이선스를 캡션에 붙인다
2. **도식**은 원문이 인라인 SVG로 그린 것을 **그대로 가져온다** (글꼴만 본문에 맞춤)
3. **수식**은 한 줄로 읽을 수 있게 정리한다 (기호와 값은 원문 그대로)
4. **접힌 블록**은 펼쳐서 제자리에 두고 테두리로 구분한다

### 3. 정리본 — `AI에이전트2기교육_YYYYMMDD_<주제>.html` → `.pdf`

원문의 **재편집본**. 조판 규칙은 → `references/lecture-doc.md`

### 4. 학습템플릿 — `학습템플릿_YYYYMMDD_<주제>.md` + `.html` → `.pdf`

섹션 구성은 → `references/study-template.md`
md → html 은 손으로 옮기지 말고 직전 회차 html의 `<style>` 을 떼어 붙여 변환한다.

```python
import re, markdown
style = re.search(r'<style>.*?</style>', open(직전회차_html, encoding='utf-8').read(), re.S).group(0)
body  = markdown.markdown(open(md, encoding='utf-8').read(), extensions=['extra','sane_lists','nl2br'])
```

### 5. 노션 붙여넣기용 — `노션붙여넣기_YYYYMMDD_<주제>.md`

절단 규칙은 → `references/notion-paste.md`

### 6. 발표대본 — `발표대본_YYYYMMDD_<주제>.md`

대본 규칙과 시간 실측은 → `references/talk-script.md`

---

파일명은 예외 없이 `<종류>_YYYYMMDD_<주제>.<확장자>`.
같은 날 **같은 종류를 둘 만들면 종류 이름을 갈라 준다** (`질문답변` / `질문답변노션`).

## 판단 기준

**도해 — 원본이 있으면 다시 그리지 않는다.** 순서는 이렇다.

1. **원문의 도식이 인라인 SVG인지 먼저 확인한다.** 모두의연구소 노드는 대개 SVG다 — `references/modulabs-node.md` 의 추출 절.
   SVG면 **`outerHTML` 을 그대로 가져다 쓴다.** 벡터라 인쇄 품질이 가장 좋고, 원문과 어긋날 일도 없다.
   **고치는 것은 글꼴 하나뿐이다** — `.nodefig svg text { font-family:var(--kr) !important }` 로 글자만 본문 글꼴에 맞추고
   **도형·색·배치는 손대지 않는다.** 캡션에 "노드 원문의 도식"이라고 밝힌다.
2. **원문에 도식이 없는 대목**(표나 글로만 설명한 자리)에 그림이 필요하면 그때 직접 그린다.
   이 경우 캡션에 **"직접 그린 도해"**라고 적어 원본과 구분한다.

**사진 — 라이선스를 확인하고, 되면 싣는다.** 노드의 사진은 대개 **위키미디어 커먼즈의 CC BY-SA** 이고 원문이 저작자를 밝혀 둔다.
그러면 **내려받아 싣되 원문이 밝힌 저작자·라이선스를 캡션에 그대로 붙인다.**
라이선스를 알 수 없거나 재사용이 막힌 사진만 빼고, **그때는 사진 설명에 있던 정보를 본문 박스로 옮겨 보존한다.**
원본이 6000px처럼 크면 **긴 변 1200px로 줄여** 넣는다(인쇄에 충분하고 PDF가 가벼워진다).

**어느 쪽을 택했든 그 방침을 정리본 표지에 한 문단으로 밝힌다** — 무엇을 원본 그대로 썼고 무엇을 직접 그렸는지.

**분량** — 정리본은 원문을 요약하지 않는다. 재편집이지 축약이 아니다. 학습템플릿은 반대로 **전체를 콜아웃 5~7개로 압축**한다.

**회고** — 직전 회차 학습템플릿의 회고를 읽고 **이어 쓴다.**
*"어제 …라고 적었는데 오늘은 …"* 형식. '보완할 점'에는 다음 회차에 확인할 **구체적 행동**을 남긴다.
직전 회고에서 약속한 것을 지켰는지 **작업 폴더를 실제로 확인해** 따지고, 못 했으면 **못 했다고 적는다.**

**사실** — 날짜·수치·출처는 **원문에 있는 것만** 쓴다. 원문에 없으면 비워 두고 `(확인 필요)`로 표시한다. 지어내지 않는다.
원문 밖에서 보탠 내용이 있으면 **`[보충]` 같은 표시로 갈라** 어디까지가 원문인지 드러낸다.

**낭독 시간** — 어림하지 않는다. 반드시 `scripts/reading_time.py`로 센다.
**대본 상단 표의 숫자는 스크립트 출력을 그대로 옮긴다.** 먼저 적어 두고 나중에 맞추지 않는다.

**글꼴** — PDF를 뽑은 뒤 반드시 `scripts/check_fonts.py`로 확인한다.
**KoPub·Consolas 외의 글꼴이 잡히면 KoPub에 없는 글자가 섞인 것**이니 찾아서 바꾸고 다시 뽑는다.
자주 걸리는 글자는 → `references/lecture-doc.md` 의 글리프 절, 그리고 `check_fonts.py` 첫머리 주석.

## 통과 기준

만들고 끝내지 말고 아래를 **실제로 확인한 뒤** 결과를 보고한다.

- [ ] 파일 6종(+PDF 3~4개)이 규칙대로 생성됐다 — `ls`로 확인
- [ ] PDF가 **0바이트가 아니고**, 쪽수가 잡힌다
- [ ] **`check_fonts.py`가 전부 `OK`** — 폴백 글꼴이 없다
- [ ] 발표대본 상단의 낭독 시간이 **실측값**이다 (스크립트 출력과 일치)
- [ ] 원문 보관본 표지에 **바꾼 네 가지**가 적혀 있다
- [ ] **원문에 SVG 도식이 있는데 직접 그린 것이 없다** — 있으면 원본으로 바꾼다
- [ ] 직접 그린 도해는 캡션에 **"직접 그린 도해"**라고 밝혀져 있다
- [ ] 사진마다 **저작자와 라이선스**가 캡션에 붙어 있다
- [ ] 정리본 표지에 **도식·사진 처리 방침**이 적혀 있다
- [ ] 회고가 **직전 회차와 이어져** 있고, 지난 약속의 이행 여부를 **폴더를 확인해** 적었다
- [ ] 링크로 받았다면 **접힌 토글을 전부 펼쳐** 읽었다

## 도구

```bash
# HTML → PDF (헤드리스 Chrome). 출력 경로는 절대경로로 준다
bash scripts/html2pdf.sh <입력.html> <출력.pdf>

# 낭독 시간 실측 (자수, 초, [줄일 때 뺄 곳] 제외 시간)
python scripts/reading_time.py <대본.md>

# PDF에 임베드된 글꼴 확인 — 폴백이 있으면 exit 1
python scripts/check_fonts.py <파일.pdf> [...]
```
