# 수업 노드 → 학습자료 5종

강의 원문 한 덩이를 받아, 날짜 폴더에 배포용 자료 다섯 개를 만든다.
**원문은 사람이 붙여넣는다** — 웹에서 긁어 오지 않는다.

## 시작 전에 확인할 것

원문을 받으면 아래 네 가지를 먼저 정한다. 사용자가 안 알려줬으면 **묻지 말고 원문에서 뽑되, 정한 값을 알린다.**

| 항목 | 정하는 법 |
|---|---|
| 날짜 | 수업일. 오늘이 아닐 수 있으니 원문·요청에서 찾는다 |
| 주제 | 공백 없는 한글 축약어 (`데이터베이스`, `에이전트와스킬`) |
| 출력 폴더 | `<작업폴더>/YYYY년MM월DD일/` |
| 직전 회차 | 같은 부모 폴더의 가장 최근 날짜 폴더. **있으면 그 스타일을 승계한다** |

## 순서

1. **직전 회차를 먼저 읽는다.** 있으면 정리본 HTML의 CSS와 학습템플릿 구성을 그대로 이어받는다. 없으면 `assets/print.css`로 시작한다.
2. **정리본** `AI에이전트2기교육_YYYYMMDD_<주제>.html` 작성 → `scripts/html2pdf.sh`로 PDF.
   조판 규칙은 → `references/lecture-doc.md`
3. **학습템플릿** `학습템플릿_YYYYMMDD_<주제>.md` + 같은 이름의 `.html` → PDF.
   섹션 구성은 → `references/study-template.md`
4. **노션 붙여넣기용** `노션붙여넣기_YYYYMMDD_<주제>.md`.
   절단 규칙은 → `references/notion-paste.md`
5. **발표대본** `발표대본_YYYYMMDD_<주제>.md`.
   대본 규칙과 시간 실측은 → `references/talk-script.md`

파일명은 예외 없이 `<종류>_YYYYMMDD_<주제>.<확장자>`.

## 판단 기준

**도해** — 원문의 사진·스크린샷은 **넣지 않는다**(저작권·출력 품질). 다만 *정보를 담고 있던* 그림은 **인라인 SVG로 다시 그린다.** 그리고 그 편집 방침을 정리본 표지에 한 문단으로 밝힌다. 사진 설명에만 있던 정보는 본문 박스로 옮겨 보존한다.

**분량** — 정리본은 원문을 요약하지 않는다. 재편집이지 축약이 아니다. 학습템플릿은 반대로 **전체를 콜아웃 5~7개로 압축**한다.

**회고** — 직전 회차 학습템플릿의 회고를 읽고 **이어 쓴다.**
*"어제 …라고 적었는데 오늘은 …"* 형식. '보완할 점'에는 다음 회차에 확인할 **구체적 행동**을 남긴다.
직전 회고에서 약속한 것을 지켰는지 먼저 따지고, 못 했으면 **못 했다고 적는다.**

**사실** — 날짜·수치·출처는 **원문에 있는 것만** 쓴다. 원문에 없으면 비워 두고 `(확인 필요)`로 표시한다. 지어내지 않는다.

**낭독 시간** — 어림하지 않는다. 반드시 `scripts/reading_time.py`로 센다.

## 통과 기준

만들고 끝내지 말고 아래를 **실제로 확인한 뒤** 결과를 보고한다.

- [ ] 파일 5종(+PDF 2개)이 규칙대로 생성됐다 — `ls`로 확인
- [ ] PDF 두 개가 **0바이트가 아니고**, 쪽수가 잡힌다
- [ ] 발표대본 상단의 낭독 시간이 **실측값**이다 (스크립트 출력과 일치)
- [ ] 정리본 표지에 **도해 재작성 방침**이 적혀 있다
- [ ] 회고가 **직전 회차와 이어져** 있다

## 도구

```bash
# HTML → PDF (헤드리스 Chrome)
bash scripts/html2pdf.sh <입력.html> <출력.pdf>

# 낭독 시간 실측 (자수, 초, [줄일 때 뺄 곳] 제외 시간)
python scripts/reading_time.py <대본.md>
```
