# 수업 노드 → 학습자료 4종

강의 원문을 받아, 날짜 폴더에 학습자료를 만든다.
**정리본 PDF · 학습템플릿 md+PDF · 노션 붙여넣기용 md**, 그리고 구간이 정해졌을 때만 **발표대본 md**.

**원문은 두 갈래로 들어온다.**

| 들어오는 형태 | 할 일 |
|---|---|
| 사람이 본문을 붙여넣음 | 그대로 쓴다 |
| **`learn.modulabs.co.kr` 노드 링크** | 브라우저로 직접 읽어 온다 → **`references/modulabs-node.md`** |

> **원문 보관본을 따로 만들지 않는다.** 예전에는 `노드원문_…` 파일을 별도로 뒀는데,
> 정리본과 내용이 겹쳐 같은 것을 두 번 읽게 됐다. **정리본 하나가 원문 전문을 그대로 담는다.**

> **날짜 폴더에는 `.pdf` 와 `.md` 만 남긴다** (2026-09-14 결정).
> **HTML 은 PDF 를 뽑기 위한 중간 파일**이므로 스크래치패드에서 만들고 폴더에 남기지 않는다.
> 읽을 때 PDF 한 벌이면 충분하고, 같은 내용이 두 형식으로 있으면 어느 쪽이 최신인지 헷갈린다.
>
> **그래서 조판 스타일은 직전 회차 파일에서 물려받지 않는다** — 물려받을 HTML 이 폴더에 없다.
> `assets/lecture.css`(정리본)와 `assets/study.css`(학습템플릿)가 그 자리를 대신한다.
> 스타일을 고칠 일이 있으면 **이 두 파일을 고친다.**

## 언제 만드는가 — 예습이 기본이다 (2026-09-14 결정)

**수업에 들어가기 전에 미리 만들어 둔다.** 수업 중에 자료를 만들면 수업을 못 듣는다.
미리 만들어 두면 **PDF 를 펴 놓고 따라가며 밑줄만 그으면 된다.**

그런데 **수업 전에 알 수 없는 것이 셋** 있다. 이건 미리 쓰지 않는다 — 지어내게 되기 때문이다.

| 언제 | 무엇을 만드나 |
|---|---|
| **수업 전 (예습)** | 정리본 PDF · 학습템플릿 md+PDF · 노션 붙여넣기용 md<br>단, **오늘의 역할·오늘의 회고·실습 의미의 '얻은 것'은 빈칸**으로 두고 `(수업 후에 채움)` 이라고 적는다 |
| **수업 뒤 (마무리)** | **회고와 '얻은 것'을 채우고** 학습템플릿 PDF 와 노션 md 만 다시 뽑는다.<br>발표 구간이 정해졌으면 **그때 대본을 추가로** 만든다 |

**정리본은 다시 만들지 않는다.** 원문 전문이라 수업을 듣는다고 달라지지 않는다.
다시 뽑는 것은 **학습템플릿 PDF 와 노션 md 둘뿐**이고, 스크립트라 1분이면 끝난다.

**날짜는 만든 날이 아니라 수업일로 단다.** 자료가 그 수업에 속하기 때문이다 —
전날 밤에 만들어도 폴더와 파일명은 수업일이다.

## 시작 전에 확인할 것

아래 다섯 가지를 먼저 정한다. 사용자가 안 알려줬으면 **묻지 말고 정하되, 정한 값을 알린다.**

| 항목 | 정하는 법 |
|---|---|
| 날짜 | **수업일**로 단다. 만든 날이 아니다 — 전날 밤에 미리 만들어도 폴더·파일명은 수업일 |
| 주제 | 공백 없는 한글 축약어 (`데이터베이스`, `트랜스포머로가는길`) |
| 출력 폴더 | `<작업폴더>/YYYY년MM월DD일/` |
| 직전 회차 | 같은 부모 폴더의 가장 최근 날짜 폴더. **회고를 이어 쓰려고 읽는다** (스타일은 `assets/` 에서 가져온다) |
| 원문 범위 | **노드 전체인지 일부 강인지.** 링크는 대개 한 강만 가리킨다 — 커리큘럼에서 전체 강 수를 확인한다 |

**물어야 하는 것은 둘뿐이다.**

1. **수업일** — 미리 만드는 경우, 오늘이 아닐 수 있다. 요청이나 커리큘럼에서 못 찾으면 묻는다
2. **발표 구간** — 아래 5단계를 볼 것

나머지는 묻지 않는다.

## 순서

### 0. 원문을 확보한다

링크로 들어왔으면 **`references/modulabs-node.md`** 를 그대로 따른다. 요약하면 —
**로그인은 사용자가 직접 / 강은 커리큘럼 목록을 클릭해 하나씩 / 클릭 뒤 5~6초 기다린 다음 읽기 /
「깊이 보기」·「손으로 돌려보기」 접힌 토글을 전부 펼쳐서 다시 읽기 /
도식과 사진은 `get_page_text` 로 안 오므로 DOM 에서 직접 꺼내기.**

**접힌 토글을 빼먹으면 자료의 절반이 날아간다.** 여기가 가장 잘 빠지는 자리다.

### 1. 직전 회차를 읽는다

**조판 스타일은 `assets/lecture.css`·`assets/study.css` 에서 가져온다.** 직전 회차 파일을 뒤지지 않는다.

직전 회차에서 읽을 것은 **`학습템플릿_….md` 의 회고 하나뿐**이다.
**이건 수업 뒤 마무리 단계에서 필요하다** — 예습 단계에서는 읽지 않아도 된다.
마무리 때 그 회고에 적힌 약속을 지켰는지 **작업 폴더를 실제로 확인해** 따진다.

### 2. 정리본 — `AI에이전트2기교육_YYYYMMDD_<주제>.pdf`

**본문 HTML 은 스크래치패드에서 조립해 PDF 만 날짜 폴더에 둔다.** 조각을 나눠 쓰고
`<!--STYLE-->` 과 `<!--SVG:이름-->` 자리를 남겨 스크립트로 끼워 넣으면, 원본 SVG 를 그대로 쓰면서
**끼워 넣을 때만** KoPub 에 없는 글자를 바꿀 수 있다.

**이 문서가 원문 전문을 그대로 담는다.** 요약도 재편집도 아니다.
조판 규칙은 → **`references/lecture-doc.md`**

**본문에 손대지 않는다**

- **문장을 한 글자도 고치지 않는다.** 줄이지도, 순서를 바꾸지도, 말투를 다듬지도 않는다
- **강 순서 그대로** `SECTION 01 … NN` 으로 싣는다. 한 강이 한 섹션이다
- **접힌 「깊이 보기」·「손으로 돌려보기」도 펼쳐서 제자리에** 둔다 — 테두리 박스로 구분만 한다
- **실습 코드와 실행 결과**도 그대로 싣는다

**우리 자료로 만드는 것은 껍데기뿐이다**

- 표지(학습 목표·산출물·편집 방침), 목차, 섹션 표제, 쪽 나눔
- 각 섹션 첫머리의 `keyline` — **원문에서 뽑은 문장을 인용**한다. 내가 지어내지 않는다
- 마지막 섹션 — **핵심 정리 표와 "수업에서 확인할 것". 여기만 내 글이다**
  (**회고는 여기 쓰지 않는다** — 예습 때는 쓸 수 없고, 학습템플릿 한 곳에서만 관리한다)

**바꾸는 것은 셋뿐이고, 표지에 그 셋을 명시한다**

1. **사진** — 라이선스를 확인해 되면 그대로 싣고 저작자·라이선스를 캡션에 붙인다
2. **도식** — 원문이 인라인 SVG로 그린 것을 그대로 가져온다 (글꼴만 본문에 맞춤)
3. **수식** — 한 줄로 읽을 수 있게 정리한다 (기호와 값은 원문 그대로)

### 3. 학습템플릿 — `학습템플릿_YYYYMMDD_<주제>.md` + `.pdf`

**md 가 원본이고 PDF 는 그것을 인쇄한 것이다.** 중간 html 은 스크래치패드에 두고 폴더에 남기지 않는다.
섹션 구성은 → `references/study-template.md`

**예습 단계에서는 두 칸을 비운다** — `오늘의 역할`(팀에서 정해짐)과 `오늘의 회고`(수업을 들어야 씀).
지우지 말고 **제목은 남긴 채 `(수업 후에 채움)`** 이라고 적어 둔다. 나머지 칸은 원문만으로 다 쓸 수 있다.

**`오늘의 실습 의미`(2026-10-20 추가)** — 실습 강마다 **왜 하나 / 얻은 것 / 할 수 있게 되는 것** 세 칸을 둔다.
노드가 "무엇을 하라"만 말하고 "왜, 하고 나면 무엇을 할 수 있나"는 거의 말하지 않아서 넣었다.
예습 때는 '왜 하나'와 '할 수 있게 되는 것'만 쓰고 **'얻은 것'은 `(수업 후에 채움)`** — 해 봐야 아는 것이라서다.
규칙은 → `references/study-template.md` 의 같은 이름 절.

```python
import markdown
from pathlib import Path
css  = Path(스킬)/'assets'/'study.css'
body = markdown.markdown(Path(md).read_text(encoding='utf-8'),
                         extensions=['extra', 'sane_lists', 'nl2br'])
```

**md 를 쓸 때부터 `✓ ✗ ④ ≈ −` 를 피한다.** 각각 SegoeUISymbol·Noto Serif KR 로 폴백해
PDF 를 두 번 뽑게 만든다 (2026-09-14에 실제로 그랬다).

### 4. 노션 붙여넣기용 — `노션붙여넣기_YYYYMMDD_<주제>.md`

절단 규칙은 → `references/notion-paste.md`

**손으로 옮겨 적지 말고 학습템플릿 md 에서 스크립트로 뽑아낸다.** 내용이 글자 하나까지 같아야 하는데
두 번 쓰면 반드시 어긋난다. 뽑아낸 뒤 **각 `=====` 블록이 학습템플릿 안에 그대로 있는지 대조**한다
(굵게·따옴표·이모지만 정규화해서 비교).

### 5. 발표대본 — `발표대본_YYYYMMDD_<주제>.md`

**발표 구간은 내가 고르지 않는다.** 그날 팀 그룹 학습에서 정해지고, **사용자가 알려 준다.**

| 상황 | 할 일 |
|---|---|
| 사용자가 구간을 알려줬다 | **그 구간만으로** 대본을 쓴다 |
| 아직 안 정해졌다 | **대본을 만들지 않고 1~4단계만 내놓는다.** 그리고 한 줄로 묻는다 — *"발표 구간이 정해지면 알려주세요. 그 부분으로 대본을 만들겠습니다."* |
| 나중에 알려줬다 | 그때 대본만 **추가로** 만든다. 앞의 네 개는 다시 만들지 않는다 |

**구간을 짐작해서 쓰지 않는다.** 엉뚱한 대목으로 3분 대본을 써 두면 버리는 일이 된다.
구간 지정은 이런 식으로 들어온다 — *"오늘 나는 3강 맡았어"*, *"어텐션 부분 발표야"*, *"5절 데이터 쪽"*.

대본 규칙과 시간 실측은 → `references/talk-script.md`

### 6. 수업 뒤 마무리 — 회고를 채운다

예습으로 만들어 둔 자료에 **수업을 듣고 나서야 쓸 수 있는 것**을 채우는 단계다.

1. `학습템플릿_….md` 의 **`오늘의 역할`** 을 채운다 (이끄미 / 시간지킴이)
2. **`오늘의 실습 의미`의 '얻은 것'** 을 채운다 — 실습에서 **실제로 화면·파일·출력으로 확인한 것만.**
   실습을 같이 했다면 그 대화에서 나온 발견(예: 에이전트 말과 파일 기록이 어긋난 지점)을 쓴다.
   못 한 실습은 "못 했다"고 적는다
3. **`오늘의 회고`** 를 채운다 — 직전 회차 회고를 읽고 이어 쓰고,
   거기서 약속한 것을 지켰는지 **작업 폴더를 확인해** 따진다. 못 했으면 못 했다고 적는다
4. `학습템플릿_….pdf` 를 다시 뽑고, `노션붙여넣기_….md` 를 다시 뽑는다 (스크립트, 1분)
5. 발표 구간이 정해졌으면 **그때 대본을 만든다**

**정리본 PDF 는 건드리지 않는다.** 원문 전문이라 수업을 들어도 달라지지 않는다.

### 다 만들었으면 세션을 끊는다

**자료를 내놓은 뒤에는 "이어서 이야기할 게 있으면 새 세션에서 하자"고 한 줄로 안내한다.**
같은 세션에서 논의를 이어가면 **매 답변마다 정리본 원문 전문까지 다시 읽어** 토큰이 크게 든다.
2026-09-14 실측 — 자료 생성 735만, 그 뒤 논의 608만. **논의가 생성만큼 먹었다.**

## 판단 기준

**도해 — 원본이 있으면 다시 그리지 않는다.** 순서는 이렇다.

1. **원문의 도식이 인라인 SVG인지 먼저 확인한다.** 모두의연구소 노드는 대개 SVG다 — `references/modulabs-node.md` 의 추출 절.
   SVG면 **`outerHTML` 을 그대로 가져다 쓴다.** 벡터라 인쇄 품질이 가장 좋고, 원문과 어긋날 일도 없다.
   **고치는 것은 글꼴 하나뿐이다** — `.nodefig svg text { font-family:var(--kr) !important }` 로 글자만 본문 글꼴에 맞추고
   **도형·색·배치는 손대지 않는다.** 캡션에 "노드 원문의 도식"이라고 밝힌다.
2. **원문에 도식이 없는 대목**(표나 글로만 설명한 자리)에 그림이 필요하면 그때 직접 그린다.
   이 경우 캡션에 **"직접 그린 도해"**라고 적어 원본과 구분한다.

**사진 — 라이선스를 확인하고, 되면 싣는다.** 노드의 사진은 대개 **위키미디어 커먼즈의 CC BY-SA** 이고 원문이 저작자를 밝혀 둔다.
그러면 **내려받아 싣되 원문이 밝힌 저작자·라이선스를 캡션에 그대로 붙인다.**
라이선스를 알 수 없거나 재사용이 막힌 사진만 빼고, **그때는 사진 설명에 있던 정보를 본문 박스로 옮겨 보존한다.**
원본이 6000px처럼 크면 **긴 변 1200px로 줄여** 넣는다(인쇄에 충분하고 PDF가 가벼워진다).

**어느 쪽을 택했든 그 방침을 정리본 표지에 한 문단으로 밝힌다** — 무엇을 원본 그대로 썼고 무엇을 직접 그렸는지.

**분량 — 정리본은 원문보다 짧아지면 안 된다.** 요약도 재편집도 아니고 **전문을 옮긴 것**이다.
빠진 문단이 있으면 그건 실수다. 학습템플릿은 반대로 **전체를 콜아웃 5~7개로 압축**한다.
**둘의 역할이 다르다** — 정리본은 다시 읽으려고, 학습템플릿은 붙잡으려고 만든다.

**회고** — 직전 회차 학습템플릿의 회고를 읽고 **이어 쓴다.**
*"어제 …라고 적었는데 오늘은 …"* 형식. '보완할 점'에는 다음 회차에 확인할 **구체적 행동**을 남긴다.
직전 회고에서 약속한 것을 지켰는지 **작업 폴더를 실제로 확인해** 따지고, 못 했으면 **못 했다고 적는다.**

**사실** — 날짜·수치·출처는 **원문에 있는 것만** 쓴다. 원문에 없으면 비워 두고 `(확인 필요)`로 표시한다. 지어내지 않는다.
원문 밖에서 보탠 내용이 있으면 **`[보충]` 같은 표시로 갈라** 어디까지가 원문인지 드러낸다.

**낭독 시간** — 어림하지 않는다. 반드시 `scripts/reading_time.py`로 센다.
**대본 상단 표의 숫자는 스크립트 출력을 그대로 옮긴다.** 먼저 적어 두고 나중에 맞추지 않는다.

**글꼴** — PDF를 뽑은 뒤 반드시 `scripts/check_fonts.py`로 확인한다.
**KoPub·Consolas 외의 글꼴이 잡히면 KoPub에 없는 글자가 섞인 것**이니 찾아서 바꾸고 다시 뽑는다.
자주 걸리는 글자는 → `references/lecture-doc.md` 의 글리프 절, 그리고 `check_fonts.py` 첫머리 주석.

## 통과 기준

만들고 끝내지 말고 아래를 **실제로 확인한 뒤** 결과를 보고한다.

- [ ] 파일이 규칙대로 생성됐다 — `ls`로 확인
      (발표 구간이 정해졌으면 4종, 아니면 3종 + 대본은 보류라고 보고)
- [ ] **날짜 폴더에 `.html` 이 하나도 남아 있지 않다** — 중간 파일은 스크래치패드에 두고 온다
- [ ] PDF가 **0바이트가 아니고**, 쪽수가 잡힌다
- [ ] **`check_fonts.py`가 전부 `OK`** — 폴백 글꼴이 없다
- [ ] **정리본에 원문의 모든 강이, 빠진 문단 없이** 들어갔다 — 섹션 수와 강 수를 세어 맞춘다
- [ ] 정리본의 `keyline` 이 **원문 문장의 인용**이다 — 내가 지어낸 문장이 아니다
- [ ] **원문에 SVG 도식이 있는데 직접 그린 것이 없다** — 있으면 원본으로 바꾼다
- [ ] 직접 그린 도해는 캡션에 **"직접 그린 도해"**라고 밝혀져 있다
- [ ] 사진마다 **저작자와 라이선스**가 캡션에 붙어 있다
- [ ] 정리본 표지에 **도식·사진·수식 처리 방침**이 적혀 있다
- [ ] 발표대본을 만들었다면 **사용자가 지정한 구간**이고, 낭독 시간이 **실측값**이다
- [ ] **예습 단계라면** `오늘의 역할`·`오늘의 회고`·실습 의미의 **'얻은 것'** 이 `(수업 후에 채움)` 으로 비어 있다 — 지어내지 않았다
- [ ] 학습템플릿에 **`오늘의 실습 의미`** 가 있고, 실습 강마다 세 칸이 있으며 '할 수 있게 되는 것'이 **그 도구 밖으로 옮겨 쓸 수 있는 행동**으로 적혀 있다
- [ ] **마무리 단계라면** 회고가 **직전 회차와 이어져** 있고, 지난 약속의 이행 여부를 **폴더를 확인해** 적었다
- [ ] 링크로 받았다면 **접힌 토글을 전부 펼쳐** 읽었다

## 도구

**중간 HTML 은 스크래치패드에, PDF 는 날짜 폴더에.** 입력과 출력의 폴더가 다르므로
`html2pdf.sh` 의 **출력 경로를 반드시 절대경로로** 준다.

사진을 `<img src="사진/…">` 로 거는데 HTML 과 사진 폴더가 떨어져 있으면 PDF 에 사진이 빠진다.
**조립할 때 사진 경로를 날짜 폴더 기준 절대경로(`file:///…`)로 박거나**, 중간 HTML 을
날짜 폴더 안에 잠깐 뒀다가 PDF 를 뽑고 **지운다.** 어느 쪽이든 **PDF 안의 이미지 개수를 세어 확인한다.**

```bash
# 학습템플릿 md → 중간 HTML (스크래치패드에). 실습 의미 절도 처리한다
python scripts/build_study.py <학습템플릿.md> <스크래치/study.html> --warn 4

# 학습템플릿 md → 노션 붙여넣기용 md + 블록 대조 (mismatch [] 이어야 한다)
python scripts/build_notion.py <학습템플릿.md> <노션붙여넣기.md> YYYY-MM-DD <주제>

# HTML → PDF (헤드리스 Chrome). 출력 경로는 절대경로로 준다
bash scripts/html2pdf.sh <입력.html> <출력.pdf>

# PDF 에 사진이 실제로 들어갔는지 (img 태그 수와 맞아야 한다)
python -c "import re,sys;print(len(re.findall(rb'/Subtype\s*/Image', open(sys.argv[1],'rb').read())))" <파일.pdf>

# 낭독 시간 실측 (자수, 초, [줄일 때 뺄 곳] 제외 시간)
python scripts/reading_time.py <대본.md>

# PDF에 임베드된 글꼴 확인 — 폴백이 있으면 exit 1
python scripts/check_fonts.py <파일.pdf> [...]
```
