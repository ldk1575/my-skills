# 설정하기

## 1. obs-websocket 켜기

OBS를 켜고 **도구 → WebSocket 서버 설정**.

| 항목 | 값 |
|---|---|
| 웹소켓 서버 사용 | **체크** |
| 서버 포트 | `4455` (기본값 그대로) |
| 인증 사용 | 체크 (권장) |
| 서버 비밀번호 | **연결 정보 표시**를 눌러 복사 |

확인을 누르면 바로 적용된다. OBS를 다시 켤 필요는 없다.

⚠️ 이 설정은 **OBS를 정상 종료할 때 파일에 저장**된다. 켠 직후 OBS를 강제 종료하면 설정이 날아갈 수 있다.

## 2. 설정.json

`scripts/감시기.py`를 처음 실행하면 옆에 만들어진다. 비밀번호만 채우면 끝.

```json
{
  "zep_키워드": ["ZEP", "zep.us"],
  "요일": [0, 1, 2, 3, 4],
  "시작시각": "09:30",
  "종료시각": "19:30",
  "여유_분": 10,
  "폴링_초": 20,
  "obs_경로": "C:\\Program Files\\obs-studio\\bin\\64bit\\obs64.exe",
  "obs_호스트": "localhost",
  "obs_포트": 4455,
  "obs_비밀번호": "여기에 붙여넣기"
}
```

| 항목 | 뜻 |
|---|---|
| `zep_키워드` | 창 제목에 이 중 하나가 있으면 수업으로 본다. 대소문자 무시. Zoom·Teams를 쓰면 여기 추가 |
| `요일` | 0=월 … 6=일. 주말도 수업이면 `[0,1,2,3,4,5]` |
| `여유_분` | Zep이 사라진 뒤 이만큼 기다렸다 멈춘다. 쉬는 시간이 길면 늘린다 |
| `폴링_초` | 몇 초마다 확인할지. 짧게 하면 반응이 빠르지만 CPU를 조금 더 쓴다 |

⚠️ **비밀번호가 들어 있으므로 저장소에 올리지 않는다.** `.gitignore`에 넣어 뒀다.

## 3. Zep은 별도 창으로

이 감시기는 **보이는 창의 제목**을 읽는다. 브라우저 창 제목은 **활성 탭**만 반영하므로, Zep을 다른 탭 뒤에 두면 감지되지 않는다.

**Zep 탭을 끌어내 별도 창으로 만들어 두는 습관**이 필요하다. 창을 최소화하는 건 괜찮다 — 제목은 그대로 남는다.

지금 무엇이 감지되는지 보려면:

```bash
python scripts/감시기.py --status
```

## 4. 자동 실행 등록

로그인할 때 감시기가 자동으로 뜨게 한다.

```powershell
powershell -ExecutionPolicy Bypass -File scripts/등록.ps1
```

지우려면:

```powershell
powershell -ExecutionPolicy Bypass -File scripts/등록.ps1 -제거
```

등록되면 **로그인 때마다 조용히 뜬다.** 감시 시간대 밖에는 아무 일도 하지 않으므로 켜 둬도 부담이 없다.

## 5. 잘 되는지 보는 법

로그가 `scripts/로그/YYYY-MM.log`에 쌓인다. **상태가 바뀔 때만** 적히므로 길지 않다.

```
2026-09-08 09:30:02  감시 시작 — 월화수목금 09:30~19:30 · 20초마다 확인
2026-09-08 10:04:21  Zep 발견 — 녹화 시작 (ZEP - 아이펠 캠퍼스)
2026-09-08 12:31:40  Zep이 안 보입니다 — 10분 더 기다립니다
2026-09-08 12:41:41  Zep 없음 10분 경과 — 녹화 중지 D:\녹화\2026-09-08 10-04-21.mkv
```

## 문제 해결

**OBS 연결이 계속 '안 됨'**
`netstat -an | findstr 4455` 로 포트가 열렸는지 본다. 안 보이면 웹소켓 서버가 안 켜진 것.

**비밀번호를 넣었는데도 실패**
앞뒤 공백이 붙었을 수 있다. 따옴표 안에 정확히 붙여넣는다.

**녹화 파일이 어디 있는지 모르겠다**
OBS → 설정 → 출력 → 녹화 경로. 로그에도 중지할 때 경로가 찍힌다.

**감시기가 두 개 떠 있다**
작업 관리자에서 `python.exe`를 확인한다. 등록 스크립트는 같은 이름의 작업을 덮어쓰므로 중복 등록은 안 된다.
