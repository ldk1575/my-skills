# 수업 녹화 자동 시작

Win+G로 손수 녹화하면 **켜는 걸 까먹는다.** 그 사람 몫을 없앤다.
Zep(또는 지정한 창)이 뜨면 OBS 녹화를 켜고, 사라지고 여유 시간이 지나면 끈다.

## 먼저 확인할 것

이 셋이 안 되어 있으면 나머지는 의미가 없다. **순서대로 확인한다.**

1. **OBS 설치** — 기본 경로 `C:\Program Files\obs-studio\bin\64bit\obs64.exe`
2. **obs-websocket 켜짐** — OBS → 도구 → WebSocket 서버 설정 → *웹소켓 서버 사용* 체크
3. **비밀번호가 `설정.json`에** 들어 있음 — 같은 화면의 *연결 정보 표시*에서 복사

설정 자세히는 → `references/설정하기.md`

## 순서

```bash
python scripts/감시기.py --status    # 1. 지금 상태 확인
python scripts/감시기.py --dry-run   # 2. 판단만 시켜 보기 (OBS 안 건드림)
python scripts/감시기.py             # 3. 상주 실행
```

1. `--status`로 **여섯 줄**을 본다 — 시각 / 감시 시간대 / Zep 창 / OBS 실행 / OBS 연결 / 녹화 상태.
   **OBS 연결이 '안 됨'이면 여기서 멈추고** 위 2·3번을 먼저 고친다
2. `--dry-run`을 켠 채 Zep 창을 열었다 닫아 본다. 로그에 `[가정] …시작하겠습니다` / `…중지하겠습니다`가 찍히는지 본다
3. 실제로 한 번 돌려 mp4가 생기는지 확인한 뒤, 작업 스케줄러에 올린다 → `scripts/등록.ps1`

## 판단 규칙

```
평일 09:30 ~ 19:30            ← 이 창 안에서만 움직인다
   ├ Zep 창 발견              → 녹화 시작
   ├ Zep 사라지고 10분 경과    → 녹화 중지
   └ 19:30 도달               → 무조건 중지
```

**여유 10분을 두는 이유** — 쉬는 시간에 Zep을 잠깐 닫거나 새로고침해도 끊기지 않게. 그 10분은 조용하니 나중에 `무음제거`로 잘라내면 된다.

설정은 `scripts/설정.json` — 요일·시간대·키워드·여유·폴링 간격을 여기서 바꾼다. 파일이 없으면 처음 실행할 때 만들어 준다.

## 수업 중에 손으로 조종하기

강사가 시간을 딱딱 맞추지 않으면 자동만으로는 부족하다. `scripts/녹화.py`로 끼어든다.

```bash
python scripts/녹화.py         # 상태
python scripts/녹화.py 정지     # 일시정지  ← 쉬는 시간엔 이것
python scripts/녹화.py 재개
python scripts/녹화.py 토글     # 정지 ↔ 재개
python scripts/녹화.py 대기     # 감시기 잠재우기
python scripts/녹화.py 해제
```

⚠️ **'중지'가 아니라 '정지'를 쓴다.** 중지는 파일을 끊어 한 수업이 조각나고, Zep이 떠 있으면 감시기가 20초 안에 다시 켠다. **일시정지는 같은 파일을 이어 쓰고**, 감시기도 '녹화 중'으로 보므로 건드리지 않는다.

정말 멈춰야 하면 **`대기` → `중지`** 순서로. 다시 자동으로 돌리려면 `해제`.

한 단어로 쓰려면 PowerShell 프로필에 등록한다 (→ `정지`, `재개`, `토글`, `녹화상태` …).

```powershell
powershell -ExecutionPolicy Bypass -File scripts/명령등록.ps1
```

## 손대지 않는 것

- **이미 녹화 중이면 건드리지 않는다.** 사람이 손수 시작한 녹화를 끊지 않는다
- **중지는 반드시 websocket으로.** OBS 프로세스를 죽이면 mp4가 깨진다
- **OBS 자체를 끄지 않는다.** 녹화만 멈추고 창은 남긴다
- 감시 시간대 **밖에서는 아무것도 하지 않는다**

## 통과 기준

만들거나 고친 뒤 **실제로 확인하고** 결과를 보고한다.

- [ ] `--status`의 여섯 줄이 다 채워지고, **OBS 연결이 '됨'**이다
- [ ] `--dry-run`에서 Zep 창을 열고 닫으면 판단이 로그에 찍힌다
- [ ] 실제 실행에서 mp4가 생기고 **재생된다**
- [ ] 감시 시간대 밖(예: 새벽)엔 Zep을 열어도 **아무 일도 없다**
- [ ] 손수 녹화 중일 때 감시기를 켜도 **녹화가 안 끊긴다**

## 자주 막히는 곳

| 증상 | 확인 |
|---|---|
| OBS 연결 '안 됨' | 웹소켓 서버 체크 / 포트 4455 / 비밀번호 오타 |
| Zep을 켰는데 감지 안 됨 | **백그라운드 탭이면 제목에 안 뜬다.** Zep은 별도 창으로 |
| 녹화가 자꾸 끊김 | `여유_분`을 늘린다 (기본 10) |
| 녹화 화질이 나쁨 | OBS 설정 문제 — 이 스킬 범위 밖 |
| 녹화가 느림 | `무음제거` 배치와 **QSV를 함께 쓰는 중**일 수 있다 |
